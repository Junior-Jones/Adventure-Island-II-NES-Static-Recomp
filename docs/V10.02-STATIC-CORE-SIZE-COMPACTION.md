# V10.02 static-core size compaction

V10.02 replaces the repeated per-identity C switch bodies with exact generated
instruction descriptors and one shared compact executor. Each descriptor retains
the admitted physical-bank/PC identity, statically selected semantic function,
operand, legal successor identities, dynamic-target policy and stack-dispatch
flag. The executor does not fetch or decode an opcode and every missing bank, PC
or dynamic target still fails closed.

The admitted manifest remains 16,544 identities across the same physical banks.
Two clean generations were byte-identical with generated-tree aggregate SHA-256
`cd09bf3c2b035d6ef40b2c7a15ca2bd083a20463f29537769af56f97a1f8f2f0`.

## Measured size result

| Artifact | Before | After | Reduction |
|---|---:|---:|---:|
| Generated C | 6,177,630 bytes | 2,977,386 bytes | 51.80% |
| MSVC Release static library | 2,130,020 bytes | 917,122 bytes | 56.94% |
| Windows `Launcher.exe` | 3,970,560 bytes | 3,532,288 bytes | 11.04% |
| Equivalent Release ZIP | 2,320,282 bytes | 1,805,125 bytes | 22.20% |

## Equivalence evidence

- The V05 fixed-dispatch contract passes all 16 checks.
- The V06 static-source audit passes with 99 fixed official semantic forms and no
  runtime opcode fetch/decode.
- The archived direct-switch core and compact core produce identical JSON after
  2,000,000 no-input instructions: bank 15, PC 62105, 6,150,893 CPU cycles,
  206 frames, no runtime trap and no PPU error.
- The compact core independently repeats that endurance run twice identically.
- The opaque public API, snapshot and observation-hook suite passes 65 checks.
- A fresh MSVC x64 Release launcher build succeeds.

The source-format change updates the compatibility identity to
`1e3e374a618dfc1e04357b56f86813c4ca5be94130d7acb4e4c39d81897b5597`.
Older snapshots are deliberately rejected rather than silently loaded across a
changed generated-core identity.

This compaction does not close the remaining native/oracle cold-boot differential
described by the static-core status document.
